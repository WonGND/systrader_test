## 기록 규칙
- 사용자 승인이 필요한 결정은 승인 확인 후에만 기록한다.
- 판정 기준(CLAUDE.md §7) 변경 시 버전을 올리고 여기에 반드시 남긴다.
- 화이트리스트(`config/ticker_whitelist.yaml`) 항목 추가는 전부 여기에 기록한다.

# NEEDS IMAGE REVIEW

텍스트만으로 재현 불가한 글의 누적 목록 (hard_constraint #2 / CLAUDE.md §1.3).

**원칙**: 이미지 안 수치를 "아마 이랬을 것"으로 추정하지 않는다.
해당 글은 삭제하지 않고 여기에 누적하여, 추후 사용자가 직접 확인할 수 있게 남긴다.

**주의**: 이 파일에는 원문 텍스트/이미지를 복사하지 않는다. URL·제목·사유만 기록한다.

---

## 분류 사유 코드
- `PARAM_IN_IMAGE` — 전략 파라미터가 이미지에만 존재
- `PERF_IN_IMAGE` — 성과 수치(CAGR/MDD 등)가 이미지에만 존재
- `RULE_IN_IMAGE` — 매매 규칙 자체가 도표/차트로만 서술
- `CODE_IN_IMAGE` — 코드 스크린샷으로만 제공

# OPEN QUESTIONS

사용자 확인이 필요한 미결 항목. 각 항목에는 **권장안**을 반드시 붙인다(CLAUDE.md §10).
해소된 항목은 삭제하지 말고 "resolved" 표시 후 결정을 DECISIONS.md로 옮긴다.

---

## 상태 범례
- `blocking` — 답변 전까지 다음 단계 진행 불가
- `non-blocking` — 권장안 기본값으로 진행 가능하나 확인받는 편이 나음
- `resolved` — 해소됨 (DECISIONS.md 참조)
